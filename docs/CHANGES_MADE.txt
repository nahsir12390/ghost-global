===== CHECKOUT REFACTORING - COMPLETE CHANGES =====

PROBLEM SOLVED:
- cURL error 28: Operation timed out after 30002 milliseconds
- Cause: Nested HTTP requests during checkout trying to process payment in same request cycle

SOLUTION IMPLEMENTED:
- Two-step checkout process: Address Collection → Payment Processing
- Separates concerns into different request cycles
- Eliminates timeout issues

===== NEW REQUEST FLOW =====

OLD FLOW (Causes timeout):
GET /checkout
  ↓
POST /checkout (in Livewire: POST to checkout.store)
  ├─ Validate address
  ├─ Create order
  ├─ HTTP to Paystack (TIMEOUT HERE if slow)
  ├─ Verify payment
  ├─ Update order
  └─ Redirect to success

NEW FLOW (No timeout):
1. GET /checkout
2. POST /checkout (checkout.store)
   ├─ Validate address
   ├─ Create order
   └─ Redirect to /checkout/{order}/payment
   
3. GET /checkout/{order}/payment
   └─ Show payment method selector
   
4. POST /checkout/{order}/process-payment
   └─ Route to Paystack or COD handler
   
5a. PAYSTACK:
   - GET /checkout/{order}/payment (shows Paystack modal)
   - User clicks "Pay with Paystack"
   - Paystack pops modal
   - User completes payment
   - Paystack redirects to /checkout/paystack/callback
   - Async HTTP to Paystack (no timeout here, separate request)
   - Redirect to /checkout/{order}/success
   
5b. CASH ON DELIVERY:
   - POST /checkout/{order}/process-payment
   - Mark order as processing
   - Send email
   - Redirect to /checkout/{order}/success

===== KEY IMPROVEMENTS =====

1. No Timeouts
   - Payment processing in separate request
   - Reduced HTTP timeout to 10s (was 30s)
   
2. Better User Experience
   - Clear separation of steps
   - User sees progress
   - Easy retry on failure
   
3. More Flexible
   - Easy to add new payment methods
   - Payment logic decoupled from order creation
   
4. Better Error Handling
   - Stock verified before order creation
   - Proper authorization checks
   - Clear error messages
   
5. Easier Testing
   - Each step is independent
   - Can test without payment processing
   - Clear logging at each step
